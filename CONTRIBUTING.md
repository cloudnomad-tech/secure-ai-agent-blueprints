# Contributing Guidelines

Thank you for contributing!

## Backend Development

- Follow Python coding conventions.
- Use type hints in application code.
- Keep FastAPI endpoints focused.
- Add appropriate error handling.
- Write automated tests.

## Frontend Development

- Use TypeScript for type safety.
- Follow accessible React patterns.
- Keep components reusable.
- Add tests for critical user flows.

## AI Engineering

- Validate structured LLM outputs.
- Document agent tool permissions.
- Test retrieval quality.
- Avoid exposing sensitive information.
- Review AI-generated code carefully.

## Security Requirements

- Never commit credentials.
- Validate authorization boundaries.
- Enforce tenant isolation.
- Add audit logging where appropriate.

## Pull Requests

1. Create a feature branch.
2. Keep changes focused.
3. Add or update relevant tests.
4. Document design decisions.
5. Submit a pull request.
